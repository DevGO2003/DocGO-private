# Hoàn tất HeaderPanel + sửa lỗi JSX

## Phạm vi
- Hoàn tất thay `TitlePanel` → `HeaderPanel` và xoá `TitlePanel` nếu không còn dùng.
- Sửa lỗi JSX/state ở các trang đã nêu để build/lint xanh.

## File tác động chính
- `frontend/web-app/src/components/ui/HeaderPanel.tsx`
- `frontend/web-app/src/components/ui/index.ts`
- `frontend/web-app/src/components/ui/TitlePanel.tsx` (xóa sau khi thay xong)
- Trang sử dụng `HeaderPanel`:
  - `src/app/(documents)/documents/page.tsx`

  - `src/app/(dashboard)/dashboard/page.tsx`

  - `src/app/(users)/profile/page.tsx`
  - `src/app/(analytics)/analytics/page.tsx`

## Bước thực hiện
1) Rà soát và sửa lỗi JSX/state còn lại
- `documents/page.tsx`: soát cặp ngoặc/JSX khối grid/list, sửa lỗi “) expected” gần cuối file.
- `import-document/page.tsx`: bổ sung state còn thiếu cho OCR flow (`selectedFile`, `ocrLoading`, `extractedText`, `isOcrModalOpen`, `isOcrDragActive`...), đảm bảo modal OCR đóng/mở đúng thứ tự, khép `</DashboardLayout>` chuẩn.

2) Thay `TitlePanel` → `HeaderPanel`
- Grep toàn repo với từ khóa `TitlePanel` và đổi import/JSX sang `HeaderPanel`.
- Đảm bảo props tương thích: giữ `variant`, thêm `compact`/`maxHeights` nếu cần.

3) Thu dọn component cũ
- Khi không còn tham chiếu `TitlePanel`, xóa `src/components/ui/TitlePanel.tsx` và loại bỏ export liên quan trong `index.ts`.

4) Kiểm thử responsive header
- Kiểm tra max-height theo breakpoint: desktop 300px, tablet 240px, mobile 200px; `overflow-hidden`/`line-clamp` không tràn.

5) Lint và build
- Chạy lint cho các file trên, sửa lỗi nếu có.
- Chạy dev build để đảm bảo chạy được.

6) Bàn giao
- Commit: `refactor(ui): unify HeaderPanel + fix JSX, responsive caps`.
- Cập nhật README dev (mục UI) về `HeaderPanel` thay `TitlePanel` và cách chỉnh `maxHeights`.
