# Kế hoạch: Hot Reload + Kafka Test + API Debug

## Bước 1: Kiểm tra Kafka đã tắt hoàn toàn

### 1.1. Kiểm tra không có Kafka consumers running
- Chạy `docker exec document-management-service ps aux | grep kafka` để kiểm tra không có process Kafka
- Chạy `docker exec automation-service ps aux | grep kafka` để kiểm tra không có process Kafka
- Kiểm tra logs của các services không còn Kafka connection attempts

### 1.2. Xác nhận cấu hình Kafka disabled
- Xác nhận `backend/document-management-service/src/main/resources/application.properties`:
  - `spring.kafka.enabled=false`
  - `spring.autoconfigure.exclude=org.springframework.boot.autoconfigure.kafka.KafkaAutoConfiguration`
- Xác nhận `backend/automation-service/config.py`:
  - `KAFKA_ENABLED: bool = os.getenv("KAFKA_ENABLED", "false").lower() == "true"`

## Bước 2: Cấu hình Hot Reload cho Docker Compose

### 2.1. Document Management Service (Spring Boot)
**Vấn đề hiện tại:** Dockerfile build production JAR, không hỗ trợ hot reload

**Giải pháp:**
- Tạo `backend/document-management-service/Dockerfile.dev`:
  ```dockerfile
  FROM eclipse-temurin:17-jdk
  WORKDIR /app
  RUN apt-get update && apt-get install -y maven && rm -rf /var/lib/apt/lists/*
  COPY pom.xml .
  RUN mvn dependency:go-offline -B
  EXPOSE 8002
  CMD ["mvn", "spring-boot:run", "-Dspring-boot.run.jvmArguments=-agentlib:jdwp=transport=dt_socket,server=y,suspend=n,address=*:5005"]
  ```

- Cập nhật `docker-compose.yml`:
  ```yaml
  document-management-service:
    build:
      context: ./backend/document-management-service
      dockerfile: Dockerfile.dev  # Thay đổi
    volumes:
      - ./backend/document-management-service:/app  # Mount source code
      - maven-repo:/root/.m2  # Cache Maven dependencies
      - ./backend/document-management-service/uploads:/app/uploads
      - ./logs/document-management:/app/logs
  ```

- Thêm volume `maven-repo` vào section volumes

### 2.2. Automation Service (FastAPI)
**Vấn đề hiện tại:** Dockerfile không có `--reload` flag

**Giải pháp:**
- Tạo `backend/automation-service/Dockerfile.dev`:
  ```dockerfile
  FROM python:3.11-slim
  WORKDIR /app
  RUN apt-get update && apt-get install -y gcc g++ libmagic1 && rm -rf /var/lib/apt/lists/*
  COPY requirements.txt .
  RUN pip install --no-cache-dir -r requirements.txt
  RUN mkdir -p results uploads
  EXPOSE 8003
  ENV PYTHONPATH=/app
  ENV PYTHONUNBUFFERED=1
  CMD ["uvicorn", "main:app", "--host", "0.0.0.0", "--port", "8003", "--reload"]
  ```

- Cập nhật `docker-compose.yml`:
  ```yaml
  automation-service:
    build:
      context: ./backend/automation-service
      dockerfile: Dockerfile.dev  # Thay đổi
    volumes:
      - ./backend/automation-service:/app  # Đã có, giữ nguyên
      - ./backend/automation-service/uploads:/app/uploads
      - ./backend/automation-service/results:/app/results
      - ./logs/automation:/app/logs
  ```

### 2.3. API Gateway (Next.js)

## Bước 3: Rebuild và restart services

### 3.1. Rebuild document-management-service và automation-service
```bash
docker-compose build --no-cache document-management-service automation-service
```

### 3.2. Restart tất cả services
```bash
docker-compose up -d
```

### 3.3. Kiểm tra logs
```bash
docker-compose logs -f document-management-service automation-service
```
