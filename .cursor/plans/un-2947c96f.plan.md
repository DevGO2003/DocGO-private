# Kế hoạch triển khai: Hoàn tất HeaderPanel + sửa lỗi JSX còn lại

## Phạm vi

- Hoàn tất thay thế `TitlePanel` → `HeaderPanel` và xoá `TitlePanel` nếu không còn dùng.
- Sửa lỗi JSX/State còn lại để build/lint xanh.
- Không chạm thư mục `(documents)` theo nghĩa tài liệu upload cũ ngoài phạm vi UI common.

- frontend/web-app/src/components/ui/

- src/app/(documents)/documents/page.tsx

## Việc cần làm cụ thể

1) Sửa JSX lỗi còn lại

- `src/app/(documents)/documents/page.tsx`: đảm bảo khép thẻ đúng ở khối grid/list; lỗi “) expected” gần line ~848 → soát cặp ngoặc/JSX đóng mở, chạy lint lại.
- `src/app/(documents)/import-document/page.tsx`:
- Khai báo state còn thiếu cho OCR flow: `selectedFile`, `ocrLoading`, `extractedText`, `isOcrModalOpen`, `setOcrDragActive`, … (đang bị báo “Cannot find name …”).
- Khớp lại modal OCR cuối file (đóng `</DashboardLayout>` đúng thứ tự).

2) Hoàn tất thay `TitlePanel` → `HeaderPanel`

- Rà grep toàn bộ `TitlePanel` và đổi import/JSX sang `HeaderPanel` ở các file còn sót.
- Cập nhật props nếu khác biệt (giữ `variant`, thêm `compact` nếu cần).

3) Thu dọn component cũ

- Nếu grep không còn `TitlePanel`, xoá `src/components/ui/TitlePanel.tsx` và loại bỏ mọi export liên quan.

4) Kiểm thử responsive header

- Xác nhận max-height theo breakpoint:
- Desktop ≥1280px: 300px
- Tablet 768–1279px: 240px
- Mobile <768px: 200px
- Kiểm tra cắt nội dung (line-clamp/overflow-hidden) không tràn.

5) Kiểm tra/lint/build

- Chạy lint cho các file trên, sửa lỗi nếu có.
- Chạy dev build để đảm bảo chạy được.

6) Bàn giao

- Tạo 1 commit: “refactor(ui): unify HeaderPanel + fix JSX, responsive caps”.
- Ghi chú ngắn vào README dev (mục UI): `HeaderPanel` thay `TitlePanel`, cách chỉnh `maxHeights`.
