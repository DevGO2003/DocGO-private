Docker Local - Compose commands

Các lệnh compose dùng cho môi trường local (không recreate, không build lại).

Start all

docker compose -f docker-compose.local.yml up -d --no-recreate --no-build

Start selected services (skip kafka if conflicting)

docker compose -f docker-compose.local.yml up -d --no-recreate --no-build redis api-gateway-bff authentication-identity-service contract-management-service ai-processing-service file-storage-service web-nextjs

Status

docker compose -f docker-compose.local.yml ps

Logs

# All
docker compose -f docker-compose.local.yml logs -f

# One service
docker compose -f docker-compose.local.yml logs -f web-nextjs

Down

docker compose -f docker-compose.local.yml down

Fix Kafka conflict

docker rm -f docgo-local-kafka
docker compose -f docker-compose.local.yml up -d --no-recreate --no-build kafka
