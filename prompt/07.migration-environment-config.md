# Migration Environment Configuration

## Prompt
```
Bạn là một chuyên gia DevOps và environment configuration. Nhiệm vụ của bạn là tạo cấu hình environment cho kiến trúc mới 5 services với cloud database.

## Yêu cầu cụ thể:

### 1. Tạo file .env.simplified cho tất cả services:
```bash
# MongoDB Atlas (Cloud) - Thay thế MariaDB local
MONGODB_ATLAS_URI=mongodb+srv://username:password@cluster.mongodb.net/docgo?retryWrites=true&w=majority

# Redis Cloud (Cloud) - Thay thế Kafka local
REDIS_CLOUD_HOST=redis-12345.c1.us-east-1-1.ec2.cloud.redislabs.com
REDIS_CLOUD_PORT=12345
REDIS_CLOUD_PASSWORD=your_redis_password

# JWT Secret
JWT_SECRET=your_jwt_secret_key_here

# AI Service - Gemini API
GEMINI_API_KEY=your_gemini_api_key

# S3/Filebase - Cloud Storage
S3_ENDPOINT=https://s3.filebase.com
S3_ACCESS_KEY=your_access_key
S3_SECRET_KEY=your_secret_key
S3_BUCKET_NAME=docgo-files

# SMTP - Email notifications
SMTP_HOST=smtp.gmail.com
SMTP_PORT=587
SMTP_USERNAME=your_email@gmail.com
SMTP_PASSWORD=your_app_password

# Service URLs
AUTH_SERVICE_URL=http://authentication-identity-service:8001
CONTRACT_SERVICE_URL=http://contract-management-service:8002
AI_SERVICE_URL=http://ai-processing-service:8003
FILE_SERVICE_URL=http://file-storage-service:8004
```

### 2. Cập nhật application.properties cho Spring Boot services:

#### authentication-identity-service/src/main/resources/application.properties:
```properties
# Server Configuration
server.port=8000
spring.application.name=authentication-identity-service

# MongoDB Atlas Configuration
spring.data.mongodb.uri=${MONGODB_ATLAS_URI}
spring.data.mongodb.database=docgo

# Redis Cloud Configuration
spring.redis.host=${REDIS_CLOUD_HOST}
spring.redis.port=${REDIS_CLOUD_PORT}
spring.redis.password=${REDIS_CLOUD_PASSWORD}
spring.redis.timeout=2000ms
spring.redis.lettuce.pool.max-active=8
spring.redis.lettuce.pool.max-idle=8
spring.redis.lettuce.pool.min-idle=0

# JWT Configuration
jwt.secret=${JWT_SECRET}
jwt.expiration=86400000

# SpringDoc Configuration
springdoc.swagger-ui.path=/docs
springdoc.api-docs.path=/api-docs

# Logging
logging.level.com.devgo2003.docgo=DEBUG
logging.level.org.springframework.data.mongodb=DEBUG
```

### 3. Cập nhật config.py cho FastAPI services:

#### ai-processing-service/config.py:
```python
import os
from dotenv import load_dotenv

load_dotenv()

# MongoDB Atlas Configuration
MONGODB_URI = os.getenv("MONGODB_ATLAS_URI", "mongodb://localhost:27017/docgo")

# Redis Cloud Configuration
REDIS_HOST = os.getenv("REDIS_CLOUD_HOST", "localhost")
REDIS_PORT = int(os.getenv("REDIS_CLOUD_PORT", "6379"))
REDIS_PASSWORD = os.getenv("REDIS_CLOUD_PASSWORD", "")

# AI Configuration
GEMINI_API_KEY = os.getenv("GEMINI_API_KEY", "")

# SMTP Configuration
SMTP_HOST = os.getenv("SMTP_HOST", "smtp.gmail.com")
SMTP_PORT = int(os.getenv("SMTP_PORT", "587"))
SMTP_USERNAME = os.getenv("SMTP_USERNAME", "")
SMTP_PASSWORD = os.getenv("SMTP_PASSWORD", "")

# Service Configuration
ENVIRONMENT = os.getenv("ENVIRONMENT", "development")
```

### 4. Cập nhật next.config.js cho API Gateway:

```javascript
/** @type {import('next').NextConfig} */
const nextConfig = {
  env: {
    AUTH_SERVICE_URL: process.env.AUTH_SERVICE_URL || 'http://localhost:8001',
    CONTRACT_SERVICE_URL: process.env.CONTRACT_SERVICE_URL || 'http://localhost:8002',
    AI_SERVICE_URL: process.env.AI_SERVICE_URL || 'http://localhost:8003',
    FILE_SERVICE_URL: process.env.FILE_SERVICE_URL || 'http://localhost:8004',
  },
  async rewrites() {
    return [
      {
        source: '/api/auth/:path*',
        destination: `${process.env.AUTH_SERVICE_URL}/api/v1/authentication-identity-service/auth/:path*`,
      },
      {
        source: '/api/contracts/:path*',
        destination: `${process.env.CONTRACT_SERVICE_URL}/api/v1/contract-management-service/contracts/:path*`,
      },
      {
        source: '/api/ai/:path*',
        destination: `${process.env.AI_SERVICE_URL}/api/v1/ai-processing-service/:path*`,
      },
      {
        source: '/api/files/:path*',
        destination: `${process.env.FILE_SERVICE_URL}/api/v1/file-storage-service/:path*`,
      },
    ];
  },
};

module.exports = nextConfig;
```

```bash

echo "1. MongoDB Atlas URI"
echo "2. Redis Cloud credentials"

echo "6. SMTP credentials"
echo ""
echo "Then run: docker-compose -f script/docker-compose.simplified.yml up -d"
```

```powershell
