```
Bạn là một chuyên gia Spring Boot và microservices architecture. Nhiệm vụ của bạn là mở rộng contract-management-service để tích hợp tất cả các chức năng liên quan đến contract management.

## Yêu cầu cụ thể:

### 1. Tích hợp các chức năng sau vào contract-management-service:
- **Approval Workflow**: Quy trình phê duyệt hợp đồng
- **Versioning & History**: Quản lý phiên bản và lịch sử thay đổi
- **Comments & Collaboration**: Bình luận và cộng tác
- **E-signature Integration**: Tích hợp chữ ký điện tử
- **Reminder & Scheduler**: Nhắc nhở và lịch trình
- **Audit Activity Log**: Ghi log hoạt động
- **Reporting & Analytics**: Báo cáo và phân tích
```

```
### 3. API Endpoints mới:
- `POST /api/v1/contract-management-service/contracts/{id}/approve` - Phê duyệt hợp đồng
- `GET /api/v1/contract-management-service/contracts/{id}/versions` - Lấy danh sách phiên bản
- `POST /api/v1/contract-management-service/contracts/{id}/comments` - Thêm bình luận
- `POST /api/v1/contract-management-service/contracts/{id}/esignature` - Chữ ký điện tử
- `POST /api/v1/contract-management-service/contracts/{id}/reminders` - Tạo nhắc nhở
- `GET /api/v1/contract-management-service/contracts/{id}/audit-logs` - Lấy audit logs
- `GET /api/v1/contract-management-service/reports/analytics` - Báo cáo phân tích

### 4. Cấu hình MongoDB:
- Thay đổi từ MariaDB sang MongoDB Atlas
- Cập nhật application.properties
- Tạo MongoDB repositories

### 5. Tích hợp Redis:
- Thay đổi từ Kafka sang Redis Cloud
- Cập nhật message handling
- Cấu hình Redis connection

### 6. Tuân thủ quy tắc:
- Sử dụng RestResponse cho tất cả API responses
- Tuân thủ URL naming convention
- Sử dụng GlobalExceptionHandler
- Port: 8002 (thay vì 8003)
```
