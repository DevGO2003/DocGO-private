# Migration AI Processing Service

## Prompt
```
Bạn là một chuyên gia FastAPI và AI/ML integration. Nhiệm vụ của bạn là mở rộng ai-processing-service để tích hợp tất cả các chức năng AI và notification.

## Yêu cầu cụ thể:

### 1. Tích hợp các chức năng sau vào ai-processing-service:
- **AI Processing**: Extract, Summarize, OCR (hiện có)
- **Notification**: Email, SMS, Push notifications
- **Batch ETL**: Xử lý hàng loạt
- **Event Handling**: Xử lý events từ Redis

### 2. Cấu trúc code mới:
```
ai-processing-service/
├── main.py (hiện có)
├── routers.py (hiện có)
├── config.py (hiện có)
├── requirements.txt (cập nhật)
├── services/
│   ├── ai_service.py (hiện có)
│   ├── notification_service.py (mới)
│   ├── batch_service.py (mới)
│   └── event_service.py (mới)
├── schemas/
│   ├── ai_schemas.py (hiện có)
│   ├── notification_schemas.py (mới)
│   └── batch_schemas.py (mới)
└── results/ (hiện có)
```

### 3. API Endpoints mới:
- `POST /api/v1/ai-processing-service/notifications/send` - Gửi notification
- `GET /api/v1/ai-processing-service/notifications/history` - Lịch sử notification
- `POST /api/v1/ai-processing-service/notifications/templates` - Quản lý template
- `POST /api/v1/ai-processing-service/batch/process` - Xử lý hàng loạt
- `GET /api/v1/ai-processing-service/batch/status/{jobId}` - Trạng thái job
- `POST /api/v1/ai-processing-service/events/handle` - Xử lý events

### 4. Cấu hình MongoDB:
- Thay đổi từ local database sang MongoDB Atlas
- Cập nhật config.py
- Tạo MongoDB collections cho notifications và batch jobs

### 5. Tích hợp Redis:
- Thay đổi từ Kafka sang Redis Cloud
- Cập nhật message handling
- Cấu hình Redis connection cho notifications

### 6. Notification Features:
- **Email**: SMTP integration
- **SMS**: Twilio integration (optional)
- **Push**: WebSocket hoặc Server-Sent Events
- **Templates**: Quản lý template notification
- **Scheduling**: Lên lịch gửi notification

### 7. Batch Processing:
- **Job Queue**: Redis-based job queue
- **Progress Tracking**: Theo dõi tiến độ
- **Error Handling**: Xử lý lỗi và retry
- **Result Storage**: Lưu trữ kết quả

### 8. Event Handling:
- **Redis Pub/Sub**: Subscribe to events
- **Event Processing**: Xử lý events từ các service khác
- **Auto Notification**: Tự động gửi notification khi AI processing hoàn thành

### 9. Tuân thủ quy tắc:
- Sử dụng RestResponse cho tất cả API responses
- Tuân thủ URL naming convention
- Port: 8003 (thay vì 8017)
- Tích hợp với Gemini API

## Mục đích
Tích hợp tất cả chức năng AI và notification vào một service duy nhất để giảm tải CPU và đơn giản hóa kiến trúc.
```
