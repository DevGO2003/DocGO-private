# Migration File Storage Service

## Prompt
```
Bạn là một chuyên gia FastAPI và file management. Nhiệm vụ của bạn là mở rộng file-storage-asset-service để tích hợp tất cả các chức năng quản lý file.

## Yêu cầu cụ thể:

### 1. Tích hợp các chức năng sau vào file-storage-asset-service:
- **File Storage**: Upload, download, delete (hiện có)
- **Asset Management**: Quản lý tài sản file
- **General File Management**: Quản lý file tổng quát
- **File Processing**: Xử lý file cơ bản

### 2. Cấu trúc code mới:
```
file-storage-asset-service/
├── main.py (hiện có)
├── routers.py (hiện có)
├── config.py (hiện có)
├── requirements.txt (cập nhật)
├── services/
│   ├── file_service.py (hiện có)
│   ├── asset_service.py (hiện có)
│   ├── general_file_service.py (mới)
│   └── processing_service.py (mới)
├── schemas/
│   ├── file_schemas.py (hiện có)
│   ├── asset_schemas.py (hiện có)
│   └── general_schemas.py (mới)
└── uploads/ (hiện có)
```

### 3. API Endpoints mới:
- `POST /api/v1/file-storage-service/files/upload` - Upload file
- `GET /api/v1/file-storage-service/files/{fileId}` - Download file
- `DELETE /api/v1/file-storage-service/files/{fileId}` - Delete file
- `GET /api/v1/file-storage-service/files` - List files
- `POST /api/v1/file-storage-service/assets/create` - Tạo asset
- `GET /api/v1/file-storage-service/assets/{assetId}` - Get asset
- `PUT /api/v1/file-storage-service/assets/{assetId}` - Update asset
- `DELETE /api/v1/file-storage-service/assets/{assetId}` - Delete asset
- `GET /api/v1/file-storage-service/assets` - List assets
- `POST /api/v1/file-storage-service/process/convert` - Convert file
- `POST /api/v1/file-storage-service/process/compress` - Compress file
- `POST /api/v1/file-storage-service/process/extract` - Extract file

### 4. Cấu hình MongoDB:
- Thay đổi từ local database sang MongoDB Atlas
- Cập nhật config.py
- Tạo MongoDB collections cho files và assets

### 5. Tích hợp Redis:
- Thay đổi từ Kafka sang Redis Cloud
- Cập nhật message handling
- Cấu hình Redis connection cho file processing

### 6. File Processing Features:
- **File Conversion**: Chuyển đổi định dạng file
- **File Compression**: Nén file
- **File Extraction**: Giải nén file
- **File Validation**: Kiểm tra tính hợp lệ
- **File Metadata**: Lấy thông tin file

### 7. Asset Management:
- **Asset Creation**: Tạo asset từ file
- **Asset Versioning**: Quản lý phiên bản asset
- **Asset Metadata**: Thông tin chi tiết asset
- **Asset Search**: Tìm kiếm asset
- **Asset Categories**: Phân loại asset

### 8. General File Management:
- **File Organization**: Tổ chức file theo thư mục
- **File Sharing**: Chia sẻ file
- **File Permissions**: Quản lý quyền truy cập
- **File History**: Lịch sử thay đổi file
- **File Backup**: Sao lưu file

### 9. Cloud Storage Integration:
- **S3/Filebase**: Tích hợp cloud storage
- **Presigned URLs**: Tạo URL tạm thời
- **CDN Integration**: Tích hợp CDN
- **Storage Analytics**: Thống kê storage

### 10. Tuân thủ quy tắc:
- Sử dụng RestResponse cho tất cả API responses
- Tuân thủ URL naming convention
- Port: 8004 (thay vì 8012)
- Tích hợp với S3/Filebase

## Mục đích
Tích hợp tất cả chức năng quản lý file vào một service duy nhất để giảm tải CPU và đơn giản hóa kiến trúc.
```
