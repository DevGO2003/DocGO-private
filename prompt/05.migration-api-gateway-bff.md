# Migration API Gateway BFF

## Prompt
```
Bạn là một chuyên gia Next.js và API Gateway. Nhiệm vụ của bạn là cập nhật api-gateway-bff để tích hợp với kiến trúc mới 5 services.

## Yêu cầu cụ thể:

### 1. Cập nhật routing cho 5 services mới:
- **API Gateway BFF** (Port 8000) - Backend for Frontend + Routing
- **Authentication Identity Service** (Port 8001) - Xác thực và ủy quyền
- **Contract Management Service** (Port 8002) - Quản lý hợp đồng + Workflow + Versioning + Comments + E-signature + Audit
- **AI Processing Service** (Port 8003) - Xử lý AI + Notification + OCR + Batch ETL
- **File Storage Service** (Port 8004) - Lưu trữ file + Asset management

### 3. Service URLs mới:
```typescript
const SERVICE_URLS = {
  AUTH: 'http://authentication-identity-service:8001',
  CONTRACT: 'http://contract-management-service:8002',
  AI: 'http://ai-processing-service:8003',

```

### 4. API Routes mới:

#### Authentication Routes:
- `POST /api/auth/login` → `POST /api/v1/authentication-identity-service/auth/login`
- `POST /api/auth/logout` → `POST /api/v1/authentication-identity-service/auth/logout`
- `POST /api/auth/refresh` → `POST /api/v1/authentication-identity-service/auth/refresh`

#### Contract Routes:
- `GET /api/contracts` → `GET /api/v1/contract-management-service/contracts`
- `POST /api/contracts` → `POST /api/v1/contract-management-service/contracts`
- `GET /api/contracts/[id]` → `GET /api/v1/contract-management-service/contracts/{id}`
- `PUT /api/contracts/[id]` → `PUT /api/v1/contract-management-service/contracts/{id}`
- `DELETE /api/contracts/[id]` → `DELETE /api/v1/contract-management-service/contracts/{id}`
- `POST /api/contracts/[id]/approve` → `POST /api/v1/contract-management-service/contracts/{id}/approve`
- `GET /api/contracts/[id]/versions` → `GET /api/v1/contract-management-service/contracts/{id}/versions`
- `POST /api/contracts/[id]/comments` → `POST /api/v1/contract-management-service/contracts/{id}/comments`
- `POST /api/contracts/[id]/esignature` → `POST /api/v1/contract-management-service/contracts/{id}/esignature`
- `POST /api/contracts/[id]/reminders` → `POST /api/v1/contract-management-service/contracts/{id}/reminders`

#### AI Routes:
- `POST /api/ai/extract` → `POST /api/v1/ai-processing-service/extract`
- `POST /api/ai/summarize` → `POST /api/v1/ai-processing-service/summarize`
- `POST /api/ai/ocr` → `POST /api/v1/ai-processing-service/ocr`
- `POST /api/ai/notifications/send` → `POST /api/v1/ai-processing-service/notifications/send`
- `GET /api/ai/notifications/history` → `GET /api/v1/ai-processing-service/notifications/history`

#### File Routes:
- `POST /api/files/upload` → `POST /api/v1/file-storage-service/files/upload`
- `GET /api/files/[id]` → `GET /api/v1/file-storage-service/files/{id}`
- `DELETE /api/files/[id]` → `DELETE /api/v1/file-storage-service/files/{id}`
- `GET /api/files` → `GET /api/v1/file-storage-service/files`
- `GET /api/files/assets` → `GET /api/v1/file-storage-service/assets`
- `POST /api/files/assets` → `POST /api/v1/file-storage-service/assets`

### 5. Middleware cập nhật:
- **Authentication**: JWT token validation
- **Authorization**: Role-based access control
- **Rate Limiting**: API rate limiting
- **CORS**: Cross-origin resource sharing
- **Error Handling**: Centralized error handling

### 6. Service Integration:
- **Auth Service**: User authentication và authorization
- **Contract Service**: Contract management và workflow
- **AI Service**: AI processing và notifications
- **File Service**: File storage và asset management

### 7. Health Monitoring:
- **Service Health**: Kiểm tra health của các services
- **Load Balancing**: Cân bằng tải
- **Circuit Breaker**: Ngắt kết nối khi service lỗi
- **Retry Logic**: Thử lại khi gặp lỗi

- Tuân thủ URL naming convention
- Port: 8000 (giữ nguyên)
- Tích hợp với tất cả 5 services
