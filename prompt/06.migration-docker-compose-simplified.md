# Migration Docker Compose Simplified

## Prompt
```
Bạn là một chuyên gia Docker và DevOps. Nhiệm vụ của bạn là tạo file docker-compose.simplified.yml cho kiến trúc mới 5 services với cloud database.

## Yêu cầu cụ thể:

### 1. Tạo file docker-compose.simplified.yml với 5 services:
- **API Gateway BFF** (Next.js) - Port 8000
- **Authentication Identity Service** (Spring Boot) - Port 8001
- **Contract Management Service** (Spring Boot) - Port 8002
- **AI Processing Service** (FastAPI) - Port 8003
- **File Storage Service** (FastAPI) - Port 8004

### 2. Cấu hình Cloud Services:
- **MongoDB Atlas**: Thay thế MariaDB local
- **Redis Cloud**: Thay thế Kafka local
- **S3/Filebase**: Thay thế local storage

### 3. Cấu trúc file:
```yaml
# Docker Compose Simplified - 5 Core Services Only
# Database: MongoDB Atlas (Cloud)
# Message Queue: Redis Cloud (Cloud)
# Tên container: docgo-simplified

services:
  # API Gateway + BFF (Next.js)
  api-gateway-bff:
    build: 
      context: ../backend/api-gateway-bff
      dockerfile: Dockerfile
    container_name: docgo-simplified-api-gateway
    restart: unless-stopped
    ports:
      - "8000:8000"
    environment:
      - NODE_ENV=development
      - NEXT_PUBLIC_API_BASE_URL=http://localhost:8000
      - AUTH_SERVICE_URL=http://auth-service:8001
      - CONTRACT_SERVICE_URL=http://contract-service:8002
      - AI_SERVICE_URL=http://ai-service:8003
      - FILE_SERVICE_URL=http://file-service:8004
    volumes:
      - ../backend/api-gateway-bff:/app
      - /app/node_modules
    networks:
      - docgo_network_simplified

  # Authentication & Identity Service (Spring Boot)
  authentication-identity-service:
    build: 
      context: ../backend/authentication-identity-service
      dockerfile: Dockerfile
    container_name: docgo-simplified-auth-service
    restart: unless-stopped
    ports:
      - "8001:8000"
    environment:
      - SPRING_PROFILES_ACTIVE=dev
      - SPRING_DATA_MONGODB_URI=${MONGODB_ATLAS_URI}
      - SPRING_REDIS_HOST=${REDIS_CLOUD_HOST}
      - SPRING_REDIS_PORT=${REDIS_CLOUD_PORT}
      - SPRING_REDIS_PASSWORD=${REDIS_CLOUD_PASSWORD}
      - JWT_SECRET=${JWT_SECRET}
    volumes:
      - ../backend/authentication-identity-service:/app
    networks:
      - docgo_network_simplified

  # Contract Management Service (Spring Boot) - Tích hợp tất cả chức năng contract
  contract-management-service:
    build: 
      context: ../backend/contract-management-service
      dockerfile: Dockerfile
    container_name: docgo-simplified-contract-service
    restart: unless-stopped
    ports:
      - "8002:8000"
    environment:
      - SPRING_PROFILES_ACTIVE=dev
      - SPRING_DATA_MONGODB_URI=${MONGODB_ATLAS_URI}
      - SPRING_REDIS_HOST=${REDIS_CLOUD_HOST}
      - SPRING_REDIS_PORT=${REDIS_CLOUD_PORT}
      - SPRING_REDIS_PASSWORD=${REDIS_CLOUD_PASSWORD}
      - AI_SERVICE_URL=http://ai-service:8003
      - FILE_SERVICE_URL=http://file-service:8004
    volumes:
      - ../backend/contract-management-service:/app
    networks:
      - docgo_network_simplified

  # AI Processing + Notification Service (FastAPI)
  ai-processing-service:
    build: 
      context: ../backend/ai-processing-service
      dockerfile: Dockerfile
    container_name: docgo-simplified-ai-service
    restart: unless-stopped
    ports:
      - "8003:8000"
    environment:
      - ENVIRONMENT=development
      - MONGODB_URI=${MONGODB_ATLAS_URI}
      - REDIS_HOST=${REDIS_CLOUD_HOST}
      - REDIS_PORT=${REDIS_CLOUD_PORT}
      - REDIS_PASSWORD=${REDIS_CLOUD_PASSWORD}
      - GEMINI_API_KEY=${GEMINI_API_KEY}
      - SMTP_HOST=${SMTP_HOST}
      - SMTP_PORT=${SMTP_PORT}
      - SMTP_USERNAME=${SMTP_USERNAME}
      - SMTP_PASSWORD=${SMTP_PASSWORD}
    volumes:
      - ../backend/ai-processing-service:/app
      - ../backend/ai-processing-service/results:/app/results
    networks:
      - docgo_network_simplified

  # File Storage Service (FastAPI)
  file-storage-service:
    build: 
      context: ../backend/file-storage-asset-service
      dockerfile: Dockerfile
    container_name: docgo-simplified-file-service
    restart: unless-stopped
    ports:
      - "8004:8000"
    environment:
      - ENVIRONMENT=development
      - MONGODB_URI=${MONGODB_ATLAS_URI}
      - REDIS_HOST=${REDIS_CLOUD_HOST}
      - REDIS_PORT=${REDIS_CLOUD_PORT}
      - REDIS_PASSWORD=${REDIS_CLOUD_PASSWORD}
      - S3_ENDPOINT=${S3_ENDPOINT}
      - S3_ACCESS_KEY=${S3_ACCESS_KEY}
      - S3_SECRET_KEY=${S3_SECRET_KEY}
      - S3_BUCKET_NAME=${S3_BUCKET_NAME}
    volumes:
      - ../backend/file-storage-asset-service:/app
      - ../backend/file-storage-asset-service/uploads:/app/uploads
    networks:
      - docgo_network_simplified

networks:
  docgo_network_simplified:
    driver: bridge
    name: docgo_network_simplified

# Không cần volumes vì sử dụng cloud database và message queue
```

### 4. Tạo file .env.simplified:
```bash
# MongoDB Atlas (Cloud)
MONGODB_ATLAS_URI=mongodb+srv://username:password@cluster.mongodb.net/docgo?retryWrites=true&w=majority

# Redis Cloud (Cloud)
REDIS_CLOUD_HOST=redis-12345.c1.us-east-1-1.ec2.cloud.redislabs.com
REDIS_CLOUD_PORT=12345
REDIS_CLOUD_PASSWORD=your_redis_password

# JWT Secret
JWT_SECRET=your_jwt_secret_key_here

# AI Service
GEMINI_API_KEY=your_gemini_api_key

# S3/Filebase
S3_ENDPOINT=https://s3.filebase.com
S3_ACCESS_KEY=your_access_key
S3_SECRET_KEY=your_secret_key
S3_BUCKET_NAME=docgo-files

# SMTP
SMTP_HOST=smtp.gmail.com
SMTP_PORT=587
SMTP_USERNAME=your_email@gmail.com
SMTP_PASSWORD=your_app_password
```

### 5. Tạo script chạy:
```bash
# script/docker-simplified.bat
@echo off
echo Starting DocGO Simplified Architecture...
docker-compose -f script/docker-compose.simplified.yml up -d
echo DocGO Simplified Architecture started!
echo.
echo Services:
echo - API Gateway: http://localhost:8000
echo - Auth Service: http://localhost:8001
echo - Contract Service: http://localhost:8002
echo - AI Service: http://localhost:8003
echo - File Service: http://localhost:8004
echo.
echo Press any key to stop services...
pause
docker-compose -f script/docker-compose.simplified.yml down
```

### 6. Tạo script PowerShell:
```powershell
# script/docker-simplified.ps1
Write-Host "Starting DocGO Simplified Architecture..." -ForegroundColor Green
docker-compose -f script/docker-compose.simplified.yml up -d
Write-Host "DocGO Simplified Architecture started!" -ForegroundColor Green
Write-Host ""
Write-Host "Services:" -ForegroundColor Yellow
Write-Host "- API Gateway: http://localhost:8000" -ForegroundColor Cyan
Write-Host "- Auth Service: http://localhost:8001" -ForegroundColor Cyan
Write-Host "- Contract Service: http://localhost:8002" -ForegroundColor Cyan
Write-Host "- AI Service: http://localhost:8003" -ForegroundColor Cyan
Write-Host "- File Service: http://localhost:8004" -ForegroundColor Cyan
Write-Host ""
Write-Host "Press any key to stop services..." -ForegroundColor Yellow
$null = $Host.UI.RawUI.ReadKey("NoEcho,IncludeKeyDown")
docker-compose -f script/docker-compose.simplified.yml down
```

### 7. Tuân thủ quy tắc:
- Sử dụng volume mount cho development
- Cấu hình environment variables từ .env.simplified
- Sử dụng cloud services thay vì local
- Port mapping theo quy tắc mới
