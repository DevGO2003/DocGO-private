Yêu cầu của bạn là: **Triển khai đăng nhập bằng Google giữa web-nextjs và backend**

**Mô tả chi tiết:**
- Frontend: Web Next.js cần tích hợp Google OAuth để người dùng đăng nhập
- Backend: Cần tạo API endpoint để xử lý Google OAuth callback và tạo JWT token
- Database: Cần lưu thông tin user từ Google và quản lý session
- Flow: User click "Đăng nhập Google" → Redirect đến Google → Callback về backend → Tạo JWT → Trả về frontend

**Các thành phần cần phân tích:**
1. Cấu hình Google OAuth trong Google Cloud Console
2. Frontend: Tích hợp Google Sign-In SDK
3. Backend: Tạo endpoint `/auth/google/callback` 
4. Database: Schema cho user table và session management
5. Security: JWT token generation và validation
2️⃣ AI Tạo code Backend

Mô tả: Chuyên viết code backend, sửa logic, refactor, mapping log → code, tạo workflow backend.

Bạn là một AI chuyên về Backend.

Dựa trên kế hoạch từ AI Lead, hãy thực hiện nhiệm vụ sau:
-   **Nhiệm vụ:** Tạo Google OAuth backend cho DocGO
    - Tạo endpoint `POST /api/v1/auth/google/callback` để xử lý Google OAuth callback
    - Tạo service để verify Google ID token và lấy thông tin user
    - Tạo JWT token sau khi xác thực thành công
    - Tạo/cập nhật user trong database từ thông tin Google
    - Tạo endpoint `GET /api/v1/auth/me` để lấy thông tin user hiện tại

-   **Yêu cầu kỹ thuật:** 
    - Sử dụng Spring Boot (contract-management-service hoặc authentication-identity-service)
    - Sử dụng Google OAuth 2.0 Client Library
    - Tuân thủ chuẩn API DocGO (RestResponse, GlobalExceptionHandler)
    - Tích hợp với database hiện có (PostgreSQL)
    - Implement JWT với secret key an toàn
    - Viết unit test cho các service

-   **Kết quả mong muốn:** 
    - API endpoint hoạt động đúng với Google OAuth flow
    - JWT token được tạo và validate thành công
    - User data được lưu vào database
    - Pull request pass tất cả test cases

Mô tả: Tạo giao diện frontend, xử lý HTML/CSS/JS hoặc framework hiện đại, tích hợp API từ backend.

Dựa trên kế hoạch từ AI Lead và API từ team Backend, hãy thực hiện nhiệm vụ sau:
-   **Nhiệm vụ:** Tạo Google Sign-In cho web Next.js của DocGO
    - Tích hợp Google Sign-In button vào trang đăng nhập
    - Xử lý Google OAuth flow và redirect đến backend

-   **Yêu cầu kỹ thuật:**

4️⃣ AI Chạy test & Báo cáo (AI QA)

Mô tả: Chạy test cases, đánh giá code từ backend & frontend, tạo báo cáo final, highlight bug & test coverage.

Bạn là một AI chuyên về QA và kiểm thử.

Nhiệm vụ của bạn là đánh giá chất lượng của Google OAuth implementation từ team Backend và Frontend.

**Test Plan cho Google OAuth:**

**Backend Testing:**
1. **API Endpoint Testing:**
   - Test `POST /api/v1/auth/google/callback` với valid Google ID token
   - Test với invalid/expired token → expect 401 error
   - Test JWT token generation và structure
   - Test `GET /api/v1/auth/me` với valid JWT token
   - Test database user creation/update

2. **Security Testing:**
   - Test JWT token validation
   - Test CORS configuration
   - Test rate limiting (nếu có)
   - Test input validation và sanitization

**Frontend Testing:**
1. **UI/UX Testing:**
   - Test Google Sign-In button hiển thị đúng
   - Test responsive design trên mobile/desktop
   - Test loading states và error messages
   - Test redirect flow sau khi đăng nhập thành công

2. **Integration Testing:**
   - Test end-to-end OAuth flow
   - Test JWT token storage và retrieval
   - Test protected routes middleware
   - Test logout functionality

**Báo cáo cần bao gồm:**
- ✅ Chức năng hoạt động tốt
- ❌ Bug tìm thấy (kèm steps to reproduce)
- 📊 Test coverage percentage
- 🔒 Security assessment
- 💡 Đề xuất cải thiện
