# Migration Authentication Identity Service

## Prompt
```
Bạn là một chuyên gia Spring Boot và authentication. Nhiệm vụ của bạn là mở rộng authentication-identity-service để tích hợp tất cả các chức năng xác thực và quản lý người dùng.

## Yêu cầu cụ thể:

### 1. Tích hợp các chức năng sau vào authentication-identity-service:
- **Authentication**: Xác thực người dùng (hiện có)
- **Identity Management**: Quản lý danh tính
- **User Management**: Quản lý người dùng (từ user-management-service)
- **Authorization**: Phân quyền và ủy quyền
- **Session Management**: Quản lý phiên đăng nhập

### 2. Cấu trúc code mới:
```
authentication-identity-service/
├── src/main/java/com/devgo2003/docgo/auth_service/
│   ├── controller/
│   │   ├── AuthController.java (hiện có)
│   │   ├── UserController.java (mới)
│   │   ├── RoleController.java (mới)
│   │   └── SessionController.java (mới)
│   ├── service/
│   │   ├── AuthService.java (hiện có)
│   │   ├── UserService.java (mới)
│   │   ├── RoleService.java (mới)
│   │   └── SessionService.java (mới)
│   ├── entity/
│   │   ├── User.java (mới)
│   │   ├── Role.java (mới)
│   │   ├── Permission.java (mới)
│   │   └── Session.java (mới)
│   └── repository/
│       ├── UserRepository.java (mới)
│       ├── RoleRepository.java (mới)

│       └── SessionRepository.java (mới)
```

### 3. API Endpoints mới:
- `POST /api/v1/authentication-identity-service/auth/login` - Đăng nhập
- `POST /api/v1/authentication-identity-service/auth/logout` - Đăng xuất
- `POST /api/v1/authentication-identity-service/auth/refresh` - Refresh token
- `GET /api/v1/authentication-identity-service/users` - Danh sách người dùng
- `POST /api/v1/authentication-identity-service/users` - Tạo người dùng
- `GET /api/v1/authentication-identity-service/users/{id}` - Chi tiết người dùng
- `PUT /api/v1/authentication-identity-service/users/{id}` - Cập nhật người dùng
- `DELETE /api/v1/authentication-identity-service/users/{id}` - Xóa người dùng
- `GET /api/v1/authentication-identity-service/roles` - Danh sách vai trò
- `POST /api/v1/authentication-identity-service/roles` - Tạo vai trò
- `GET /api/v1/authentication-identity-service/sessions` - Danh sách phiên đăng nhập
- `DELETE /api/v1/authentication-identity-service/sessions/{id}` - Hủy phiên đăng nhập

### 4. Cấu hình MongoDB:
- Thay đổi từ MariaDB sang MongoDB Atlas
- Cập nhật application.properties
- Tạo MongoDB repositories

### 5. Tích hợp Redis:
- Thay đổi từ Kafka sang Redis Cloud
- Cập nhật message handling
- Cấu hình Redis connection cho session management

### 6. User Management Features:
- **User CRUD**: Tạo, đọc, cập nhật, xóa người dùng
- **User Profile**: Quản lý thông tin cá nhân
- **User Search**: Tìm kiếm người dùng
- **User Status**: Trạng thái người dùng (active, inactive, suspended)
- **User Groups**: Nhóm người dùng

### 7. Role & Permission Management:
- **Role CRUD**: Quản lý vai trò
- **Permission CRUD**: Quản lý quyền
- **Role Assignment**: Gán vai trò cho người dùng
- **Permission Assignment**: Gán quyền cho vai trò
- **Hierarchical Roles**: Vai trò phân cấp

### 8. Session Management:
- **Session Creation**: Tạo phiên đăng nhập
- **Session Validation**: Xác thực phiên đăng nhập
- **Session Termination**: Kết thúc phiên đăng nhập
- **Session Monitoring**: Theo dõi phiên đăng nhập
- **Multi-device Support**: Hỗ trợ đa thiết bị

### 9. Security Features:
- **JWT Tokens**: Quản lý JWT tokens
- **Password Hashing**: Mã hóa mật khẩu
- **Two-Factor Authentication**: Xác thực hai yếu tố
- **Account Lockout**: Khóa tài khoản
- **Password Reset**: Đặt lại mật khẩu

### 10. Tuân thủ quy tắc:
- Sử dụng RestResponse cho tất cả API responses
- Tuân thủ URL naming convention
- Port: 8001 (giữ nguyên)
- Sử dụng GlobalExceptionHandler

## Mục đích
Tích hợp tất cả chức năng xác thực và quản lý người dùng vào một service duy nhất để giảm tải CPU và đơn giản hóa kiến trúc.
```
