# Tóm tắt Luồng Xử lý Tài liệu và Hợp đồng

## Prompt

### **Prompt: Yêu cầu triển khai Luồng Xử lý Tài liệu và Hợp đồng (Tóm tắt)**

**Mục tiêu:**
Triển khai một luồng xử lý tài liệu tự động dựa trên kiến trúc microservices và Kafka. Hệ thống phải thực hiện chính xác các bước và sử dụng các topic Kafka đã được định nghĩa dưới đây.

**Yêu cầu kỹ thuật:**

**1. Luồng Upload và Sự kiện Ban đầu:**
*   **Hành động:** Client upload file qua API Gateway, yêu cầu được xử lý bởi `File-Storage-Service`.
*   **Kết quả:** `File-Storage-Service` lưu file và publish một event vào Kafka topic **`file.uploaded`**.

**2. Phân phối Sự kiện (Fan-out):**
*   **Hành động:** Event từ topic **`file.uploaded`** được tiêu thụ bởi hai service sau:
    1.  **`General-File-Management-Service`**: Consume event, tạo một bản ghi `FileRecord`, và publish event mới vào topic **`file.record.created`**.
    2.  **`AI-Processing-Service`**: Consume event để bắt đầu pipeline phân tích.

**3. Pipeline Xử lý của AI-Processing-Service:**
*   **Hành động:** Thực hiện một chuỗi các bước phân tích thông minh.
*   **Các bước và sự kiện tương ứng:**
    1.  Trích xuất văn bản → Publish event vào topic **`ai.text.extracted`**.
    2.  Phân loại tài liệu → Publish event vào topic **`ai.document.classified`**.
    3.  Nếu tài liệu là hợp đồng, tóm tắt và publish kết quả cuối cùng vào topic **`contract.summary.updated`**.

**4. Cập nhật Dữ liệu Hợp đồng:**
*   **Hành động:** Hoàn tất luồng xử lý bằng việc cập nhật dữ liệu vào hệ thống quản lý hợp đồng.
*   **Service chịu trách nhiệm:** `Contract-Management-Service`.
*   **Nhiệm vụ:**
    *   Consume event từ topic **`contract.summary.updated`**.
    *   Tạo mới hoặc cập nhật một hợp đồng trong cơ sở dữ liệu.
*   **Kết quả:** Publish event vào topic **`contract.updated`** để thông báo luồng xử lý đã hoàn tất.

## Mục đích
Lưu trữ prompt tóm tắt về luồng xử lý tài liệu và hợp đồng, đảm bảo các service và topic Kafka được định nghĩa rõ ràng để AI có thể triển khai nhanh chóng.

## Cách sử dụng
Copy nội dung prompt trên và paste vào chat AI để thực hiện nhanh việc triển khai hoặc rà soát hệ thống theo luồng đã định nghĩa.
