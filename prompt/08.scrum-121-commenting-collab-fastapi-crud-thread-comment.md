# SCRUM-121 — Commenting & Collaboration (FastAPI CRUD thread/comment)

## Prompt
```
Bạn là senior backend engineer. Thực hiện task SCRUM-121 cho DocGO:
- Chốt stack FastAPI (thay NestJS)
- Tạo skeleton đầy đủ CRUD cho thread/comment, sẵn sàng tích hợp Gateway WS (realtime) sau

YÊU CẦU CHUẨN HÓA (DocGO):
- Base path: `/api/v1/commenting-collaboration-service`
- Tài nguyên: `threads`, `comments` (số nhiều, kebab-case)
- Envelope `RestResponse` (apiVersion, statusCode, shortMessage, description, data, timestamp, requestId, path)
- Quy tắc 204: Không dùng HTTP 204; HTTP 200 với `statusCode: 204` trong body khi rỗng
- Docs: `/docs#/` (summary/description tiếng Việt + phần Đầu vào/Đầu ra)
- Exception: map 400/404/409/500; unexpected → `RestResponse` 500
- Cấu trúc: `main.py`, `routers.py`, `schemas/`, `services/`, `config.py`, `README.md`, `How to run this microservice.md`
- Port: 8005

ENDPOINTS (CRUD cơ bản):
THREADS
1) `POST /threads` – tạo thread `{ contractId, title, createdBy, participants? }`
2) `GET /threads` – phân trang + lọc `contractId, createdBy` (pageNumber, pageSize, sortBy, sortDirection)
3) `GET /threads/{threadId}` – chi tiết thread (kèm `lastMessageAt, totalComments`)
4) `PUT /threads/{threadId}` – cập nhật `title/participants`
5) `DELETE /threads/{threadId}` – xoá mềm

COMMENTS
6) `POST /threads/{threadId}/comments` – tạo comment `{ content, attachments?, mentionedUserIds?, actorId }`
7) `GET /threads/{threadId}/comments` – phân trang + sort
8) `PUT /comments/{commentId}` – chỉnh sửa comment (lưu `editHistory` { editedAt, editorId, before, after })
9) `DELETE /comments/{commentId}` – xoá mềm

SỰ KIỆN (để sẵn hook cho WS/Gateway):
- Phát sự kiện theo Event Payload Standard: `CommentCreated`, `CommentUpdated`, `CommentDeleted`
- Payload gồm: threadId, commentId, actor, mentions, attachments, timestamp, correlationId

SCHEMAS GỢI Ý (pydantic):
- Thread { id, contractId, title, participants[], createdBy, createdAt, updatedAt?, deletedAt?, lastMessageAt?, totalComments }
- Comment { id, threadId, content, authorId, createdAt, updatedAt?, deletedAt?, attachments[], mentionedUserIds[], editHistory[] }
- CreateThreadRequest, UpdateThreadRequest, CreateCommentRequest, UpdateCommentRequest
- PaginatedResponse<T> (result: { content, total_elements, total_pages, page_number, page_size, number_of_elements })

SERVICE LAYER:
- `CollaborationService` với các hàm:
  - `create_thread`, `list_threads`, `get_thread`, `update_thread`, `delete_thread`
  - `create_comment`, `list_comments`, `update_comment`, `delete_comment`
- Quy tắc chỉnh sửa/xoá: author hoặc admin (để TODO check quyền sau)

ROUTER LAYER:
- `router = APIRouter(prefix="/api/v1/commenting-collaboration-service", tags=["Commenting Collaboration Service"])`
- Summary/description tiếng Việt + Đầu vào/Đầu ra theo chuẩn dự án

DOCKER DEV:
- Dockerfile FastAPI chuẩn; docker-compose dev mount code; port 8005

KIỂM THỬ NHANH:
- Tạo 1 thread → thêm 3 comments → chỉnh sửa 1 comment → list comments (sort asc/desc) → xoá mềm
```
