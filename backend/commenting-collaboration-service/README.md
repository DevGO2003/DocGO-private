# Commenting Collaboration Service

Dịch vụ FastAPI quản lý thread/comment và sẵn sàng tích hợp realtime.

## Endpoints (khái quát)
- POST `/api/v1/commenting-collaboration-service/threads`
- GET `/api/v1/commenting-collaboration-service/threads`
- GET `/api/v1/commenting-collaboration-service/threads/{threadId}`
- PUT `/api/v1/commenting-collaboration-service/threads/{threadId}`
- DELETE `/api/v1/commenting-collaboration-service/threads/{threadId}`
- POST `/api/v1/commenting-collaboration-service/threads/{threadId}/comments`
- GET `/api/v1/commenting-collaboration-service/threads/{threadId}/comments`
- PUT `/api/v1/commenting-collaboration-service/comments/{commentId}`
- DELETE `/api/v1/commenting-collaboration-service/comments/{commentId}`

Docs: http://localhost:8005/docs#/
